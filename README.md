# דף הנחיתה של שיתופא

דף נחיתה סטטי בעברית (RTL) עבור **שיתופא** — תוכנה חינמית ל-Windows לשיתוף קבצים,
צ'אט וקבוצות בין מחשבים ברשת מקומית, בלי אינטרנט.

- **האתר החי:** https://lev-good.github.io/shitufa-site/
- **התוכנה:** https://github.com/Lev-Good/shitufa-app
- **פיתוח:** [לב טוב דיגיטל](https://digital.levtov.uk/)

## מה יש כאן

```
index.html               העמוד היחיד
assets/css/style.css     כל העיצוב
assets/js/main.js        תפריט, נגני יוטיוב, אנימציות
assets/js/videos.js      מזהי הסרטונים ביוטיוב (אופציונלי)
assets/fonts/            Heebo (OFL) מתארח מקומית — בלי תלות בגוגל
assets/img/              לוגו, תמונת שיתוף
videos/                  10 סרטוני ההדרכה (MP4 + תמונת פתיח לכל אחד)
docs/video-prompts.md    התסריטים + איך מפיקים אותם מחדש
_demo/                   צינור הפקת הסרטונים (לא נטען באתר)
```

אין תהליך בנייה, אין תלויות npm ואין תוספים. GitHub Pages מגיש את הקבצים כמו שהם.

## הסרטונים

10 סרטוני ההדרכה נמצאים ב-`videos/` ומתנגנים ישירות בדף (נגן `<video>` מקומי,
בלי יוטיוב ובלי קוקיז). כל כרטיס נושא `data-file` ו-`data-poster`.
הם הופקו מהממשק האמיתי — הפירוט ב-[docs/video-prompts.md](docs/video-prompts.md).

### מעבר ליוטיוב (אופציונלי)

1. מעלים את הסרטון ליוטיוב, ומוודאים ש**ההטמעה מורשית** (Allow embedding).
2. לוקחים את המזהה מתוך הכתובת: `youtube.com/watch?v=` ואז 11 תווים.
3. פותחים את `assets/js/videos.js` וממלאים:
   ```js
   v03: 'aBcD1234xyz',
   ```
4. `git commit` ו-`push`. תוך דקה GitHub Pages מפרסם את השינוי.
   ברגע שיש מזהה יוטיוב, האתר מעדיף אותו על הקובץ המקומי — ואפשר למחוק את
   ה-MP4 מ-`videos/` כדי לחסוך מקום.

כרטיס בלי מזהה ובלי קובץ מציג "הסרטון בהכנה" ולא נשבר.

## עדכון גרסה / הורדה

קישורי ההורדה מצביעים לעמוד השחרורים הציבורי של התוכנה:

```
https://github.com/Lev-Good/shitufa-releases/releases/latest
```

שני הכפתורים נפתרים בזמן אמת מעמוד השחרורים: `main.js` שולף את ה-Release
האחרון ומציב כל כפתור על הקובץ שלו — האחד על `Shitufa.Setup.<version>.exe`
והשני על `Shitufa.Portable.<version>.exe` — ומציג לידם את שם הקובץ, גודלו
ואת מספר הגרסה בראש המקטע. אין צורך לגעת בקוד בכל עדכון גרסה: פרסום Release
חדש במאגר `shitufa-releases` מספיק, והאתר יתעדכן בטעינה הבאה.

התשובה נשמרת ב-`localStorage` לחצי שעה כדי לא לשרוף את מכסת ה-API של GitHub.
אם ה-API חסום או חסר רשת — הקישורים נשארים על עמוד השחרורים, שגם הוא מוביל
לאותם שני קבצים, ולכן אין מצב של כפתור מת.

## פרסום (GitHub Pages)

האתר מוגש מענף `main`, מתיקיית השורש:

```bash
git push origin main
```

בהגדרות המאגר: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
קובץ `.nojekyll` קיים כדי ש-GitHub לא יעבד את הקבצים דרך Jekyll.

## נגישות

- עברית עם `lang="he"` ו-`dir="rtl"`, קישור דילוג לתוכן, מבנה כותרות תקין.
- ניווט מלא במקלדת, מצבי פוקוס נראים, תוויות `aria` לכפתורי הנגן.
- כיבוד `prefers-reduced-motion`, ניגודיות טקסט גבוהה, טבלה עם כיתוב לקורא מסך.
- הסרטונים מוטמעים מ-`youtube-nocookie.com` (ללא עוגיות מעקב עד הלחיצה).
